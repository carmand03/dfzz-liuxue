
This repository provides the data and documentation used for a comparative analysis of narratives surrounding Japan- and US-returned students in the intellectual journal *Dongfang zazhi* 東方雜誌 (1904–1948).

It is organized into three main folders:

1. **data**: This folder contains the two parallel corpora built from *Dongfang zazhi* 東方雜誌, one for each student group. Altogether, these datasets contain approximately 250 articles spanning the period 1905–1948.

2. **scripts**: This folder contains the R scripts used for corpus construction and text analysis (including topic modeling and sentiment analysis), as well as authorship analysis (including, notably, multiple correspondence analysis). It is subdivided into two folders, one for each corpus. Each script is provided in both Markdown and HTML formats.

3. **plots**: This folder contains various data visualizations produced in the course of the research.

This study serves as the basis for the chapter titled “Beyond ‘Revolutionaries’ and ‘Modernizers’: A Corpus-Driven, Comparative Analysis of Japanese- and American-Returned Students in *Dongfang Zazhi* 東方雜誌 (1905–1948),” in Cécile Armand, Christian Henriot, and Ling-ling Lien (eds.), *Performing Power: Elites and the Making of Modern China* (Berlin: De Gruyter, 2027), pp. 27-70.
